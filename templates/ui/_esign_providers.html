{% comment %} Reusable e-sign provider flow (Adobe eSign / DocuSign). Connection state + the account signatory name are stored client-side (localStorage), set when the user "connects" a provider on /ui/integrations/. At signing time the provider asks for a 2FA code, then applies the signature pulled from the connected account and submits the form. Usage: include once per page, then call from a provider button: EsignProviders.sign('adobe', {inputId:'inlineSigData', formId:'inlineEsignForm'}) Optional opts: commentSourceId (textarea/input id to copy into the form's [name=comments] field before submit). {% endcomment %}
